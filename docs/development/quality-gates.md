# Maven quality gates

`bash scripts/wsl/lab.sh mvn clean verify` now executes Enforcer toolchain/release-dependency/convergence checks, Spotless 3.12.0 with Google Java Format 2.0.0 AOSP, Checkstyle plugin 3.6.0/engine 14.4.0, strict compiler lint and the real unit/JAR integration tests. Only the tooling module has active formatting/style executions; future services are not silently wired into a shared runtime.

The initial build found CLI/Spotless import-order drift. Publisher guidance requires explicit `reorderImports=true` for AOSP, which now aligns both paths. No mass-format or style-pin substitution hid the failure. [Checkstyle rules](../../tools/quality/checkstyle.xml) cover tabs, package/type shape, wildcard imports, braces and short/qualified broad-catch names. These AST checks do not prove semantic ownership, retry safety or full SAST. A justified terminal-boundary catch needs a specific reviewed exception/suppression mechanism before such code is added; none is broadly disabled here.

A later build passed but warned that an inherited jvnet repository had an expired certificate. [Project Maven settings](../../.mvn/settings.xml) now mirror all remote repository IDs to verified HTTPS Central; no global settings, CA trust or certificate check was weakened. The launcher runs from repository root, so the relative settings path in .mvn/maven.config is deterministic, including `-f tools/build-verification/pom.xml`. Direct Maven from another working directory needs the explicit absolute project settings path. Private repositories require a deliberate reviewed change, not a bypass.

Run `bash scripts/wsl/verify-quality-gates.sh` to create only its owned temporary Java fixture, observe formatter and IllegalCatch failure, remove it and restore a full passing verify. It refuses to overwrite an existing fixture and never deletes unrelated source. [Evidence](../testing/evidence/P1-035-review.md) records failures/corrections and restored reports. The optional editor workspace has WSL: Verify build, using the same launcher.

Known limits: Spotless's current module helper emits a Java 25 sun.misc.Unsafe deprecation warning. Tests pass, but future JDK/tool upgrades need regression review; the warning is not suppressed. WSL's existing default user is UID 0, so these local default-session builds ran as root; no non-root user, group grant or account change was made. Prefer a reviewed non-root development account when configuring that separate host concern. No SCA/SBOM/secret scan, production security guarantee or hosted CI result is claimed by local quality success.

Rollback restores reviewed pins/options/settings with affected checks rerun. Do not disable TLS, lint, formatting or test discovery simply to make a build green; do not delete user caches or unrelated files.
