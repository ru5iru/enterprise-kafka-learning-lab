## 1. Goal and context

Configure a real Maven build in CI using the WSL reference version and existing tooling module. Do not advance to business services or claim JUnit execution yet.

## 2. Concepts explained in my own words

Maven package runs validation, quality gates, compilation and packaging. skipTests suppresses Surefire execution while still compiling test sources. Failsafe integration-test/verify occur later than package and are not reached here.

## 3. Work performed and artifact

Added checksum-pinned Maven installation plus version output, then lab.sh mvn -DskipTests clean package. Root launcher fixes working-directory-dependent .mvn settings. Hosted execution pending push.

## 4. Decisions and rationale

Reuse Maven 3.10.2 installer instead of accepting runner-preinstalled Maven or adding a new version manager. Use a cold ephemeral runner and HTTPS Central mirror with strict checksums. skipTests is an explicit task boundary, removed in P1-041. Existing ADR-0013 covers the tooling module.

## 5. Best practices and design patterns

Use thin CI around a portable build so local WSL and hosted Ubuntu share gates. Explicit plugin/dependency pins support repeatability; checksum installation is not full supply-chain attestation. No application pattern is introduced.

## 6. Common mistakes, errors and vulnerabilities

Runner Maven drift, missing project settings and dependency metadata repository failure can break builds. Version output, root launcher, Central mirror and fail-fast shell address these. A green package can conceal skipped tests; documentation states the skip and next task removes it.
