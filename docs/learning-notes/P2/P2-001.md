## 2. Concepts explained in my own words

A source tree is input, a classpath is the set of runtime/compile search entries, and a Maven module is a separately described build. None automatically equals a deployed service or a Java Platform Module System module.

| Existing path | Meaning | Review rule |
|---|---|---|
| root pom.xml | packaging=pom, shared management and aggregator | Does not itself produce an application JAR |
| tools/build-verification/pom.xml | tooling JAR with relative parent | Buildable from root with -f child; no Boot starter |
| src/main/java | Production/tooling source | Match package declaration to directories |
| src/test/java | Test source | Keep test libraries/code out of production artifact |
| src/main/resources, src/test/resources | Classpath resources when needed | Resources may be packaged; never store secrets here |
| target | Generated classes/reports/JAR | Ignored, reproducible output; never edit as source |

The repository currently uses test naming/plugins to distinguish unit tests and tooling ITs within src/test/java; a separate src/it directory is not automatically required. Packages give namespace and package-private access. A subpackage does not inherit access privileges from its parent. No module-info.java or JPMS migration is implied.

## 4. Decisions and rationale

## 5. Best practices and design patterns

Use convention over configuration, source/output separation and independent ownership. Module aggregation is build orchestration, not a shared business-domain pattern. Future services own their own POM, data and deployment; no shared mutable business model added. Framework scanning and layer generation deferred.

## 6. Common mistakes, errors and vulnerabilities

Wrong package paths hurt discoverability/case-sensitive Linux builds; all existing files matched. Packaging test sources/resources can leak fixtures/secrets; sources remain separated and target ignored. A package is not an authorization or database boundary. Rejected documentary examples are review scenarios, not executed application attacks.
