# Per-task learning journal — mandatory

Every task that reaches `Done` must have exactly one canonical Markdown learning note:

`docs/learning-notes/<phase>/<TASK-ID>.md` (for example `docs/learning-notes/P0/P0-001.md`).

Copy [TEMPLATE.md](TEMPLATE.md), **replace all placeholders with observed task-specific facts**, and connect it to the CSV row's `Evidence_Link`. The note must explain why things are designed this way and what failed or could fail; 'implemented X' is insufficient. Include decisions, rejected options, patterns, security threats, errors, tests, operational behavior, and further learning. Mark non-applicable items explicitly.

Do not pre-create 726 empty notes. Create each one only while carrying out the corresponding task; empty files are not evidence of completion. Keep the 15 phase checklists static and use the CSV as the sole status tracker.
