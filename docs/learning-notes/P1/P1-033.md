## 1. Goal and context

P1-033 turns the reviewed compiler policy into an actual build after P1-032. ADR-0013 permits only a tooling probe, preserving P2 application/P3 broker boundaries.

## 2. Concepts explained in my own words

Parent plugin management supplies versions/configuration while the child/default lifecycle activates compilation. --release chooses language/API/bytecode target, not just the JVM running Maven. A parent resolved by relativePath lets this child build without a previous reactor install.

## 3. Work performed and artifact

Added parent/child POMs, strict Maven defaults, one non-business runtime-feature fixture and module guidance; updated README to acknowledge the build. Root compilation executed the exact compiler and toolchain guards successfully. Final checks cover standalone/rejection/restoration/bytecode/effective POM.

## 4. Decisions and rationale

Use the smallest real source fixture rather than an empty green build or premature Spring service. Use Boot BOM management without adding Spring runtime code. Preserve independent child execution and exact active plugin pins. Existing ADR-0013 records the significant build design.

## 5. Best practices and design patterns

Explicit release/encoding, warnings-as-errors, disabled hidden processors, prerequisite validation and strict checksums make build assumptions observable. Aggregation is not runtime coupling. No business architecture or HTTP/Kafka/database component is introduced.

## 6. Common mistakes, errors and vulnerabilities

A compiler setting in an inactive parent or a zero-source build could give false confidence. Actual compilation/effective-POM/class inspection avoids that. Unsupported release 99 is observed rejected; the valid artifact is restored afterward. No test/quality/CI success is inferred from compile.

## 7. Testing, verification and evidence

Real root and standalone compilation passed, bad release produced its expected compiler failure, valid compilation was restored, class major 69 was observed and effective version/release matched. Evidence records only those executed checks, not future tests/integration compatibility.

## 8. Debugging and operational notes

For failure, distinguish Enforcer prerequisite, artifact resolution and javac diagnostics. Inspect the effective POM before changing flags. Rebuild after a negative clean compile so final generated state is valid; target files stay ignored. Rollback requires dependent tool-task review.

## 9. Security and SSDLC check

Build plugins execute downloaded code, so explicit pins/HTTPS/strict checksums and no credential settings are important. Enforcer permits the local source parent snapshot but requires release dependencies. No annotation processor, new repository, service listener or secret was added.
