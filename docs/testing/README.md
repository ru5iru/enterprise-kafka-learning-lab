# Verification documentation

Use the [verification record template](VERIFICATION_TEMPLATE.md) and [evidence guidance](evidence/README.md). Every Done task links an actual check/review through its CSV evidence field and canonical learning note. Label expected, observed, failed, not run and N/A separately.

Current documentary evidence: [P0 package review/index](evidence/P0-phase-review.md) and [P1-001 through P1-012 review/index](evidence/P1-001-012-review.md). These do not prove runtime correctness, security, throughput or recovery. A passing static link check does not render Mermaid or validate external uptime.

As implementation begins, put executable test code with its owning application or assigned testing directory and link small sanitized results here. Do not add empty test suites, generated binaries, large reports or pretend runtime evidence to fill a documentation tree. Consult [Definition of Done](../agent/DEFINITION_OF_DONE.md) and [SSDLC](../roadmap/SSDLC_AND_VERIFICATION.md) for applicable checks. Return to [documentation index](../README.md).
