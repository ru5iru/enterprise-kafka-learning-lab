## 1. Goal and context

Install the JDK needed by later Kafka/Java work inside Ubuntu WSL, keeping the current checkout for development. P1-012 is Done/merged. No Java service, Maven installation or JAVA_HOME configuration belongs to P1-013.

## 2. Concepts explained in my own words

A JDK includes the Java runtime and compiler. Installing it is different from selecting it through PATH/JAVA_HOME and from compiling a program. WSL executes Linux binaries while the repository may remain mounted from Windows. Artifact hashes bind downloaded bytes to a reviewed publisher reference.

## 3. Work performed and artifact

Added a root-only, architecture-checked, checksum-pinned Linux installer, WSL setup guidance and ADR-0011. Downloaded/extracted Oracle JDK into /opt/kafka-lab/jdk-25.0.5.1. Actual runtime reports 25.0.5.1+4-LTS-20; javac exists. The first negative probe failed before the installer because the nobody account has a nologin shell. Using WSL --exec bypassed that login shell and tested the actual installer root gate, which rejected it. Windows installations and global alternatives are untouched.

## 4. Decisions and rationale

Retain the existing Java reference because the current official page and installed binary agree. Use a versioned Linux directory rather than a distribution default that could select another Java line. Alternative: move the repository into WSL home; deferred because the owner chose continuing here. ADR-0011 records that filesystem/performance trade-off and Linux-only dependency boundary.

## 5. Best practices and design patterns

Fail closed on checksum mismatch and privilege/platform mismatch; do not pipe downloaded code directly into a shell. Keep acquisition, environment selection and compiler verification separate. Idempotent installation avoids overwriting unrelated tools. This is reproducible tool acquisition, not a Kafka application pattern.

## 6. Common mistakes, errors and vulnerabilities

Windows Maven previously leaked through inherited PATH and JAVA_HOME was unset; later environment setup will resolve that. A moving download could otherwise silently upgrade Java; the pinned hash prevents extraction of changed bytes. Oracle platform/terms were reviewed; support entitlement and independent authenticity are not inferred.

## 7. Testing, verification and evidence

Publisher download/hash/terms reads and real installation were executed. The evidence verifier checks Linux runtime build, executable compiler and non-root rejection. No compilation/build/runtime service test is claimed. A Spring documentation reread failed certificate validation; verification was not weakened to bypass it.

## 8. Debugging and operational notes

For TLS failures, diagnose trust/network configuration rather than using insecure download flags. For checksum failure, compare the publisher artifact/version and update only after review. The installer does not change global selection, so rollback concerns only the new versioned directory after dependency checks.

## 9. Security and SSDLC check

Boundary: public software distribution into a privileged Linux tool directory. TLS/hash, fixed architecture, root gate and no secret output apply. No credentials or keys are stored. WSL access uses explicitly approved escalated execution; later Docker permissions and runtime isolation remain separate tasks.

## 10. Lessons learned and knowledge checks

1. Installation is distinct from environment selection and functional compilation.
2. Linux tools should not resolve through Windows PATH.
3. Hash-pinning can make a mutable URL fail safely.
4. A mounted checkout preserves one tree with a performance trade-off.
Knowledge check: why not change JAVA_HOME in this task? P1-014 owns that observable behavior. Unknown: full build compatibility until later checks.

## 11. Completion decision and handoff

Acceptance is met by actual Linux installation, version observation, safe installer/recovery and negative privilege check. Only P1-013 becomes Done with evidence. Commit/push must finish before starting P1-014; no P2 application work is introduced.
