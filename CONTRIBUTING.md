# Contributing

This repository is a **learning-first, task-driven monorepo**. Before changing anything, read [AGENTS.md](AGENTS.md), the [task execution workflow](docs/agent/TASK_EXECUTION_WORKFLOW.md), and [Git conventions](docs/git/CONTRIBUTION_WORKFLOW.md).

Each change should address exactly one task ID by default, contain task-specific learning documentation, provide verifiable evidence, and respect security and phase boundaries. Use a topic branch and a Conventional Commit. Open a focused pull request using the provided template.

**Do not commit passwords, private keys, tokens, generated local environment files, or unredacted logs.**
