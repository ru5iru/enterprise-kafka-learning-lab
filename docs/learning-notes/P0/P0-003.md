## 2. Concepts explained in my own words

A scope boundary distinguishes an intended capability from a maturity claim. Kafka retries and replay are legitimate learning work; a real payment gateway is not required to teach them. A later learning target is in overall scope but is not authorized for implementation during P0. Scope, task sequencing, and production readiness are three separate questions.
